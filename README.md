# ✈ ТревелКасса — Совместный бюджет путешествия

Веб-приложение для учёта общих расходов в поездке или на мероприятии.  
Каждый участник добавляет свои траты, а приложение автоматически считает — кто кому и сколько должен.

## Возможности

- Добавление участников и трат
- Учёт разных валют (RUB, EUR, USD, GBP, TRY, THB) с автоматической конвертацией в рубли
- Автоматический расчёт долгов с минимальным количеством переводов
- Удаление трат и участников

## Установка

### 1. Убедись что Python установлен

Открой командную строку (CMD на Windows или Terminal на Mac) и напиши:

```
python --version
```

Должно появиться что-то вроде `Python 3.10.0`. Если Python не установлен — скачай его на [python.org](https://www.python.org/downloads/)

---

### 2. Скачай проект с GitHub

Нажми зелёную кнопку **Code → Download ZIP** на странице репозитория,  
распакуй архив в удобное место.

Или через git (если установлен):

```
git clone https://github.com/ТВО_ИМЯ/budget_app.git
```

---

### 3. Перейди в папку проекта

```
cd budget_app
```

---

### 4. Установи зависимости

```
pip install -r requirements.txt
```

Это установит Flask — единственную библиотеку, которая нужна приложению.

---

### 5. Запусти приложение

```
python app.py
```

---

### 6. Открой в браузере

Перейди по адресу:

```
http://127.0.0.1:5000
```

Приложение работает! 🎉
